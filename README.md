# Deteccion_de_fraude_bancario
sistema que permite implementar y ejecutar un HMM que simule secuencias de transacciones financieras, verificar que las frecuencias empíricas convergen a los valores teóricos predichos por la teoría de cadenas de Markov, y evaluar la capacidad del algoritmo de Viterbi para inferir los estados ocultos a partir de las observaciones.
